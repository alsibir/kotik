# Следующие этапы

## Подготовлено в версии 0.1.0

- Astro, три языка, две темы и системный режим.
- Учебник: 12 начальных занятий; практика: 12 связанных заданий.
- Три редакционные публикации, четыре проектных задания.
- Маршрут на 12 недель, поиск по занятиям и блогу, печать.
- Раздельные Markdown-файлы, общие компоненты и GitHub Actions.

## До открытой публикации

1. Проверить визуальное отображение и интерактивные элементы в обычном браузере на компьютере и телефоне.
2. Отредактировать английский и чешский тексты с языковым редактором.
3. Дополнить конкретные источники для отдельных статей.
4. Создать репозиторий в аккаунте взрослого, загрузить проект, включить Pages и проверить адрес публикации.

## Следующий содержательный выпуск

1. Ценности: справедливость, честность, ответственность, прощение и границы.
2. Литература: мотивы героя, рассказчик, отзыв о книге.
3. История: первичный источник, временная шкала, сравнение свидетельств.
4. Искусство: анализ картины, музейная подпись, короткая экскурсия.
5. Языки: просьба, отказ, уточнение на трёх языках.
6. Цифровая мастерская: Markdown, HTML, викторина о рассуждениях.
7. Православная традиция: отдельный подраздел, содержание согласуется с наставником.

## Следующие функциональные задачи

- Перевести задания проектов и сведения о проекте в Markdown.
- Внедрить схему статей, статусы `draft` и `published`, проверку переводов и авторство в метаданных.
- Разделить редакционные примеры и настоящие записи блога. Для авторских записей добавить дату и автора, не сочиняя биографические события.
- Разрешить публикацию неполного набора переводов с честным сообщением об отсутствующей версии; сейчас три версии обязательны.
- Добавить поиск по заданиям проектов и фильтры по времени/формату.
- При росте объёма внедрить индексируемый поиск без отправки запросов третьим сторонам.
- После определения окончательного домена добавить sitemap и метаданные для социальных сетей.
- Добавить локальные отметки выполнения только при необходимости, с пояснением отсутствия синхронизации между устройствами.

## Не входит в первую версию

Регистрация, личный кабинет, серверный дневник, комментарии, публичные оценки, общение с посетителями, автоматическая публикация текстов без проверки взрослым.


## Школа спокойной силы (ШСС), 28 уроков — ноябрь 2026

- Раздел \`/ru/shss/\` — отдельная программа из **28 уроков**, не 28 дней.
- Для каждого урока предусмотрены обзор, текст, комикс и контрольная работа.
- Урок 5: текст и комикс опубликованы. Отдельная контрольная работа пока не подготовлена.
- Остальные уроки представлены страницами-заготовками; статус материалов не завышается.
- Все пути доступны в русской, английской и чешской структуре. Непереведённый текст не выдаётся за перевод.
- Детские персональные данные, реальные эпизоды травли и данные школы не публикуются.
- Комикс урока 5 опубликован в виде четырёх полноразмерных оригинальных иллюстраций (1055 × 1491 пиксель каждая) в формате WebP высокого качества. Для просмотра и скачивания каждой страницы предусмотрены прямые ссылки; печать рассчитана на формат А4.
