# Правила разработки сайта Котика

## Назначение

Учебный сайт для возраста от 11 лет: мышление, общение, выступления, ценности, литература, история, искусство, языки и программирование. Astro, статическая публикация на GitHub Pages. Основной источник содержания — Markdown в `src/content`.

## Совместная работа

1. Перед работой проверить ветку, незакоммиченные изменения и актуальность основной ветки. Не перезаписывать чужие изменения.
2. Одной задаче соответствует отдельная ветка. Два сеанса ИИ не редактируют один файл одновременно.
3. Существенные решения фиксировать в описании задачи или ROADMAP.md: переписка между аккаунтами не является общим состоянием проекта.
4. После изменения выполнить `npm run build` и `npm run check:links`. Изменения навигации и путей дополнительно проверить со сборкой `BASE_PATH=/kotik/`.
5. Публичную публикацию материалов проверяет взрослый администратор. Не заявлять о выполненной публикации без результата GitHub Actions.
6. Не добавлять зависимости, аналитику, сетевые интеграции и формы без связи с конкретной задачей.

## Языки

Языки: `ru`, `en`, `cs`. Идентификатор и путь статьи должны соответствовать друг другу в трёх языках. Не оставлять русские тексты под английскими или чешскими заголовками. Переключение языка сохраняет текущую страницу.

## Содержание

Понятные примеры, короткие объяснения, наблюдаемые критерии выполнения. Не приписывать ребёнку опыт, события, убеждения или выполненные проекты. Редакционные примеры явно обозначать. Не учить терпеть травлю или отвечать за чужую агрессию. Общую этику и религиозную традицию обозначать раздельно.

## Данные и файлы

Не публиковать личные дневники, школу, адрес, расписание, контакты ребёнка, секреты, переписку и чужие персональные данные. Публичная история Git сохраняет прежние версии. Отсутствие страницы в сборке не скрывает исходный файл публичного репозитория.

## Оформление

Одинаковая геометрия в светлой и тёмной темах. Адаптивность, клавиатурная навигация, заметный фокус, достаточный контраст. Не вносить тяжёлую анимацию и публичные рейтинги. Не ломать базовый путь GitHub Pages жёсткими корневыми ссылками.
